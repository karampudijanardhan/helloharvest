# 🌿 HelloHarvest - AI Powered Organic Food E-Commerce Platform

HelloHarvest is a modern AI-powered organic food shopping platform built with the MERN Stack. It helps customers discover healthy organic products using Artificial Intelligence, personalized recommendations, meal planning, voice search, and more.

---

# 🚀 Features

## 🛒 E-Commerce
- Product Listing
- Product Details
- Categories
- Shopping Cart
- Checkout
- Order Management
- User Authentication
- Admin Dashboard
- Product Management
- Responsive Design

---

# 🤖 AI Features

## 🩺 AI Health Advisor
Users enter their age, gender and health goal.
AI recommends the most suitable HelloHarvest products.

---

## 🔍 AI Product Finder
Users can ask:

- I have diabetes
- I need weight loss products
- High protein foods

AI recommends products with reasons and benefits.

---

## 🥗 AI Meal Planner
Generates personalized daily meal plans based on:

- Age
- Gender
- Goal

---

## 🍲 AI Recipe Generator
Creates healthy recipes using HelloHarvest products.

Example:

- Millet Breakfast
- Healthy Smoothies
- Herbal Drinks

---

## 🎤 AI Voice Search
Users can search products using voice.

Example:

> "Show Honey"

> "Find Moringa Powder"

---

## 📷 AI Food Image Scanner
Upload a food image and receive:

- Food Name
- Calories
- Protein
- Fat
- Carbohydrates
- Health Score
- Recommended HelloHarvest Products

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/karampudijanardhan/helloharvest.git
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Backend

```bash
cd backend
npm install
npm run dev
```

---

# 🔑 Environment Variables

Backend

```
PORT=10000

MONGO_URI=YOUR_MONGODB_URL

JWT_SECRET=YOUR_SECRET

GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

Frontend

```
VITE_API_URL=http://localhost:10000
```

For Production

```
VITE_API_URL=https://your-backend.onrender.com
```
